## 📌 연구 개요

수도권과 비수도권 간 응급의료 인프라 접근성 격차가 **치료역량을 매개로** 심근경색 응급실 내 사망률에 미치는 영향을 단계적으로 분석하고, 데이터 기반 정책 방향을 제시한 연구입니다.

<br>

> 💬 **핵심 연구 질문**
>
> *"수도권과 비수도권의 응급의료 격차는 어디에서 발생하며, 어떤 요인이 응급실 내 사망률에 영향을 미치는가?"*

<br>

### 🔗 분석 인과 구조

```
┌─────────────────┐          ┌───────────────────┐          ┌──────────────────┐
│   인프라 접근성   │  ──────▶  │      치료역량       │  ──────▶  │  응급실 내 사망률  │
│                 │          │                   │          │                  │
│  · 응급기관 수   │          │  · 구급차 이용률    │          │   AMI 사망률 ★   │

└─────────────────┘          │  · 전원율          │          └──────────────────┘
                             └───────────────────┘
                ↕ 통제변수: 고령화율 (region_old), 수도권/비수도권 (metro)
```

```

```

## 🔬 분석 방법론

| # | 단계 | 분석 내용 | 기법 |
|:-:|------|-----------|------|
| 1️⃣ | **인프라 격차 검증** | 수도권 vs 비수도권 차이 확인 | Wilcoxon rank-sum test + Cohen's d |
| 2️⃣ | **교란변수 검토** | 고령화율의 혼재 효과 검토 | Spearman 상관분석 |
| 3️⃣ | **인프라 → 치료역량** | 인프라 접근성이 치료역량에 미치는 영향 | 다중회귀분석 (VIF 확인) |
| 4️⃣ | **치료역량 → 사망률** | 치료역량이 사망률에 미치는 영향 | 다중회귀분석 (log 변환) |
| 5️⃣ | **매개효과 검증** | 입원치료의 매개 경로 확인 | Bootstrap Mediation (1,000회) |
| 6️⃣ | **정책 시뮬레이션** | 치료역량 개선 시 사망률 변화 예측 | 반사실적 분석 (Counterfactual) |

## 📊 주요 분석 결과

<details>
<summary><b>🔍 Step 1 &nbsp;|&nbsp; 인프라 격차 검증</b></summary>
<br>

- 📍 **면적당 기준**: 수도권이 비수도권보다 병원 수 **15.7배**, 구급차 수 **10.6배** 높음 (p < 0.001)
- ⚠️ 인구당 기준은 비수도권이 오히려 높아 **착시효과 발생** → 면적 기준 분석이 실제 접근성을 더 정확하게 반영

<br>
</details>

<details>
<summary><b>🔍 Step 3 &nbsp;|&nbsp; 인프라 → 치료역량 관계</b></summary>
<br>

- ❌ 인프라 확충만으로는 치료역량 개선 불가 (R²=0.03~0.05)
- ✅ **인력·운영·프로토콜** 개선이 반드시 함께 필요

<br>
</details>

<details>
<summary><b>⭐ Step 4 &nbsp;|&nbsp; 치료역량 → 사망률 관계</b></summary>
<br>

| 변수 | β | p-value | 해석 |
|------|:-:|:-------:|------|
| 입원치료 제공률 (`ami_heal`) | −0.103 | < 0.001 *** | 가장 강력한 정책 효과 변수 |
| 전원율 (`ami_trans`) | −0.102 | < 0.001 *** | 적절한 전원이 생존율 향상 |

- 전체 모델 R² = **0.302**
- 비수도권에서 치료역량 설명력 더 큼 (R²=**0.318** vs 수도권 0.252)

<br>
</details>

<details>
<summary><b>⭐ Step 5 &nbsp;|&nbsp; 매개효과 검증</b></summary>
<br>

```
인프라 (병원 면적당)
      │
      │ a경로 (비유의)
      ▼
 입원치료 제공률 ──── b경로 (유의 ***) ────▶ 응급실 내 사망률

 간접효과 (ACME) = -0.393   p = 0.016 ★
```

| 경로 | Estimate | p-value | 결과 |
|------|:--------:|:-------:|------|
| ACME (간접효과) | −0.393 | 0.016 * | ✅ 유의 — 인프라→입원치료→사망률 경로 확인 |
| ADE (직접효과) | −0.305 | 0.438 | ❌ 비유의 |
| Total Effect | −0.698 | 0.194 | ❌ 비유의 |

<br>
</details>

<summary><b>🎯 Step 6 &nbsp;|&nbsp; 정책 시뮬레이션</b></summary>

|------|:------------:|:------:|
| 현재 | 1.1165% | — |
| 입원치료 +1% | 0.9066% | 📉 **−18.8%** |

**시나리오 B — 전원율 억제 시 (주의)**

| 조건 | 비수도권 사망률 | 변화율 |
|------|:------------:|:------:|

## 🎯 결론 및 정책 제언

> **비수도권 응급의료 문제의 핵심은 단순 인프라 부족이 아닌 "접근성"과 "치료 역량 부족"**

<br>

| 우선순위 | 정책 방향 | 세부 내용 |
|:--------:|----------|-----------|
| 🥇 **1순위** | 입원치료 제공 역량 강화 | 의료 인력 배치 최적화, 장비 확충, 응급 프로토콜 표준화 |
| 🥈 **2순위** | 적절한 전원 체계 구축 | 전원율 억제 정책 지양, regionalization 강화 |
| 🥉 **3순위** | 취약 지역 선택적 투자 | **13개 최우선 투자 지역** 도출 (고령화↑ + 인프라↓ + 사망률↑) |
